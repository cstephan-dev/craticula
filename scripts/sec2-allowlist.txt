# SEC-2 lint allowlist (scripts/lint-sec2.py): the reviewed trust boundaries of the query-text builders.
#
# One entry per line: `path::Type.Member | expression | reason (requirement id)`. The key is the file, the enclosing
# member and the exact expression the lint reports (whitespace collapsed), so it survives line shifts. An allowlisted
# expression is accepted as it stands and nothing inside it is traced further; an entry that no longer matches a
# finding fails the run, so this file cannot rot. Add an entry only for a value that is NOT a user value: a quoting,
# placeholder or escaping primitive's own input, a schema-declared identifier, or text that never reaches a query.
# A user value in query text is a SEC-2 defect to fix, never an entry here.
